# Review Analyzer Project

## Overview
This project analyzes product reviews using AI and sentiment analysis.

## Features
- Sentiment analysis using VADER
- Aspect-based sentiment analysis (ABSA)
- REST API backend with FastAPI
- Web frontend interface

## Installation

### Backend Setup
cd backend
pip install -r requirements.txt
python app/main.py

### Frontend Setup
Run start-frontend.bat

## Testing
python test_api.py
python test_vader.py
python test_absa.py

## Usage
1. Run start-backend.bat
2. Run start-frontend.bat
3. Open http://localhost:8000
